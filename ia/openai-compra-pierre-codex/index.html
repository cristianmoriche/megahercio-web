OpenAI comprará Pierre, cuyas librerías ya usa Codex

El 4 de noviembre de 2026, OpenAI anunció que comprará Pierre Computer Company, Inc., una startup de herramientas para programadores cuyas librerías ya usa su agente de programación Codex. No ha dado precio ni fecha de cierre.

Edición y revisión: Cristian Moriche · Publicada el 5 de noviembre de 2026 a las 09:20

Texto elaborado con ayuda de inteligencia artificial a partir de las fuentes citadas. Política editorial

Claves

  • OpenAI comprará Pierre, creadora del servicio Code Storage y de las librerías abiertas Trees y Diffs, que Codex ya emplea para mostrar archivos y cambios.
  • No se conocen el precio ni la fecha de cierre, y el trato necesita aprobaciones regulatorias; hasta entonces las dos empresas siguen separadas.
  • Las fuentes no aclaran qué funciones de Code Storage llegarán a Codex ni cuándo; los clientes actuales podrán seguir usándolo tras el cierre.

Qué ha pasado

OpenAI anunció el 4 de noviembre de 2026 que adquirirá Pierre Computer Company, Inc., una pequeña startup de herramientas para desarrolladores. Según las coberturas que recogen el anuncio de OpenAI, la compra busca ampliar las capacidades para programar que tiene Codex, su agente de programación, un programa de IA que escribe y modifica código por su cuenta. La página oficial del anuncio no se pudo abrir desde la redacción (el servidor la rechazó), así que los datos salen de las tres coberturas que lo resumen y no de OpenAI directamente.

No se ha revelado el precio. El cierre depende de las aprobaciones regulatorias habituales y, hasta entonces, ambas compañías operarán de forma independiente, según Investing.com. OpenAI incorporará al equipo técnico y a las herramientas de Pierre.

Publicidad

Qué es Pierre y qué aporta a Codex

Pierre es la empresa detrás de Code Storage, un servicio que guarda código y su historial mediante Git. Git es el sistema de control de versiones más usado: registra cada cambio de un proyecto para poder revisarlo o deshacerlo. También mantiene librerías de código abierto, entre ellas Trees y Diffs.

Según The Decoder, Trees se encarga de moverse deprisa entre los archivos de un proyecto, y Diffs muestra los cambios entre dos versiones del código y permite corregir errores desde esa misma vista. The Decoder añade una tercera, Highlights, que resalta la sintaxis en tiempo real. Las fuentes coinciden en que Codex ya usa estas herramientas, de modo que no es un fichaje de tecnología ajena: OpenAI compra algo que ya está dentro de su producto.

Qué se sabe del plan

OpenAI quiere llevar funciones de Code Storage a Codex. No ha dicho cuáles ni en qué plazo, según DEV Community. Los clientes actuales de Code Storage podrán seguir usándolo tras el cierre mientras se integra, y los proyectos abiertos de Pierre seguirán siendo abiertos.

La razón que da OpenAI, según The Decoder, es el trabajo conjunto de personas y agentes de IA sobre el mismo código: cuantas más tareas en paralelo realicen los agentes, más tendrá que adaptarse el entorno de Git. Investing.com cita además a Pando, un sistema propio de control de versiones para flujos con varios agentes. DEV Community precisa que OpenAI publicó el 2 de noviembre de 2026 una entrada técnica sobre Pando y que es compatible con Git. Investing.com añade, como información no confirmada, que habría reducido en torno a un 80 % la latencia (el retraso) al desplegar código y que OpenAI estudiaría ofrecerlo a empresas.

Y GitHub

Axios presentó la compra como un movimiento contra GitHub, la plataforma de Microsoft donde se aloja gran parte del código del mundo, según recoge DEV Community. Esa lectura es del medio: el anuncio de OpenAI, apunta la misma fuente, no menciona GitHub. Investing.com añade que GitHub domina el mercado y ha sufrido problemas de fiabilidad, una valoración del propio medio.

Por qué importa

Hasta ahora OpenAI vendía sobre todo modelos y aplicaciones; con Pierre y Pando refuerza una pieza menos visible, el lugar donde vive el código. Si los agentes escriben una parte creciente de los cambios, quien controle ese almacén y su historial tendrá mucho que decir sobre cómo se revisa, se aprueba y se despliega lo que producen. Es una lectura nuestra, no una afirmación de OpenAI, y depende de lo que acabe integrando en Codex.

Para quien programa hoy con estas herramientas no hay cambios confirmados: no consta ninguna variación en los precios, planes ni disponibilidad de Codex. Lo que sí conviene vigilar es la seguridad de esa cadena: el 31 de octubre de 2026 contamos cómo una versión manipulada de Claude Code en Cursor intentó abrir una puerta trasera. Qué falta por saber

  • El precio, la fecha de cierre y qué organismos deben aprobar el acuerdo: no encontrado en las fuentes.
  • Qué funciones de Code Storage llegarán a Codex y cuánto tiempo seguirá existiendo como producto independiente.
  • Si Pando se ofrecerá a empresas, como apunta Investing.com sin confirmación.
  • Si cambiará algo en los precios o planes de Codex: las fuentes no dicen nada.
