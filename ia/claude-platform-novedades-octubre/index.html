Claude Platform en octubre: Haiku 5.5, nueva versión de la API y plazos que vencen el 30 de noviembre

Anthropic ha publicado en octubre de 2026 un modelo nuevo, Claude Haiku 5.5, y una versión de la API con SDK que rompen compatibilidad. Una función y un modelo se retiran el 30 de noviembre.

Edición y revisión: Cristian Moriche · Publicada el 1 de noviembre de 2026 a las 00:25 · Actualizada el 1 de noviembre de 2026 a las 16:10

Texto elaborado con ayuda de inteligencia artificial a partir de las fuentes citadas. Política editorial

Claves

  • Claude Haiku 5.5 salió el 7 de octubre con 1 millón de tokens de contexto y cuesta 0,10 dólares por millón de tokens de entrada hasta 100.000 tokens.
  • El 21 de octubre llegó la versión de API 2026-10-21 y SDK nuevos que cambian de licencia, de MIT a Apache 2.0, y traen cambios incompatibles.
  • El 30 de noviembre de 2026 se retiran Claude Sonnet 4.5 y el modo rápido de Claude Opus 4.8: quien los use debe migrar antes.

Qué ha pasado

Anthropic ha anotado en las notas de versión de Claude Platform, su plataforma para desarrolladores, varias novedades entre el 7 y el 30 de octubre de 2026. Las más relevantes para quien programa con Claude:

  • 7 de octubre: Claude Haiku 5.5 (claude-haiku-5-5). Anthropic lo presenta como su modelo más capaz para trabajo de mucho volumen y poca latencia. Tiene 1 millón de tokens de contexto, hasta 128.000 tokens de salida y «pensamiento adaptativo» con el parámetro de esfuerzo, que ajusta cuánto razona el modelo. Está en la API de Claude, Amazon Bedrock, Claude Platform on AWS, Google Cloud y Microsoft Foundry.
  • 7 de octubre: caché más barata en Sonnet 5.5. La lectura de caché, que reutiliza partes ya enviadas de un prompt, baja de 0,20 a 0,10 dólares por millón de tokens.
  • 7 de octubre: SDK con herramientas de navegador. Los SDK de Python y TypeScript incluyen, en beta, clases para las herramientas de uso del navegador y del ordenador.
  • 9 de octubre: flujos de trabajo dinámicos en Claude Managed Agents (beta). El agente puede escribir un programa que lanza muchos agentes por fases, por ejemplo para revisar cientos de documentos.
  • 15 de octubre: el modo rápido sale de la vista previa en Claude Opus 5.5 y ya no hace falta pedir acceso.
  • 20 de octubre: perfiles de usuario, para indicar a Anthropic a qué cliente final corresponde cada petición, de modo que una sanción de seguridad pueda recaer en un cliente y no en toda la organización.
  • 21 de octubre: API 2026-10-21 y versiones nuevas de los SDK y de la herramienta ant.
  • 22 de octubre: Claude disponible en Google Cloud gestionado por Anthropic.
  • 28 de octubre: el tamaño máximo de petición pasa de 32 a 128 MB.
  • 29 de octubre: nueva API de analítica de uso y coste, en beta.

Precio y migración de Haiku 5.5

Según la página de precios de Anthropic (consultada el 1 de noviembre de 2026), Haiku 5.5 cuesta 0,10 dólares por millón de tokens de entrada y 0,50 de salida cuando el prompt no supera los 100.000 tokens; por encima, 0,50 y 2,50. En esa cuenta entran también las lecturas y escrituras de caché. Haiku 4.5 cuesta 1 y 5 dólares. Según VentureBeat, Anthropic calcula un coste un 75 % menor de media para la carga de trabajo. Las cifras de rendimiento que acompañan al lanzamiento son de la propia empresa y no se han contrastado de forma independiente.

Publicidad

El cambio no es un simple cambio de nombre. Según las notas de versión, el código escrito para Haiku 4.5 puede fallar: el pensamiento manual con budget_tokens, los parámetros temperature, top_p y top_k, y el prefill del mensaje del asistente pueden devolver un error 400. El pensamiento adaptativo viene activado y, si no se pide un resumen, el texto de esos bloques se omite.

Nueva versión de API y SDK

El 21 de octubre llegaron Python 2.0.0, TypeScript 1.0.0, C# 13.0.0, Go 2.0.0, Java 3.0.0, PHP 1.0.0, Ruby 2.0.0 y ant 2.0.0. Envían por defecto la versión de API 2026-10-21, traen cambios incompatibles que no dependen de ella y pasan de licencia MIT a Apache 2.0.

Retiradas del 30 de noviembre

El 30 de octubre Anthropic anunció que el modo rápido de Claude Opus 4.8 se retira el 30 de noviembre de 2026; después, las peticiones con speed: "fast" darán error. Para conservarlo, hay que pasar a Opus 5.5. Ese mismo 30 de noviembre se retira Claude Sonnet 4.5 en la API, deprecado el 30 de septiembre; el sustituto recomendado es Sonnet 5.5.

Por qué importa

Haiku 5.5 baja el listón de coste para tareas que antes pedían un modelo mayor, pero migrar no es automático: quien tenga flujos con Haiku 4.5 debe revisar parámetros y pensamiento antes de cambiar el identificador. Los SDK nuevos también obligan a probar antes de actualizar.

Publicidad

Hay además dos plazos concretos, ambos el 30 de noviembre, que afectan a quien use Claude en producción. Los perfiles de usuario interesan a quien revende o expone Claude a terceros, un caso típico de los agentes de IA integrados en productos.

Según VentureBeat, Haiku 5.5 trae reglas de ciberseguridad más estrictas que Haiku 4.5: bloquea las pruebas de penetración por defecto y el acceso ampliado se pide en los programas de verificación de Anthropic. Quien haga auditorías con el modelo debe tenerlo en cuenta. Otro ejemplo de cómo cambia el comportamiento de las herramientas de Claude entre versiones: Claude Code evita recrear videojuegos concretos.

Si dudas entre asistentes, tenemos una guía con los precios en España de ChatGPT, Gemini, Claude y Copilot.

Qué falta por saber

  • Los benchmarks de Haiku 5.5 son de la empresa; falta ver pruebas independientes.
  • VentureBeat no pudo contrastarse con la web original (no respondió): sus datos propios, como el 75 % de ahorro y las reglas de ciberseguridad, dependen de ese medio.
  • Las notas de versión detallan muchas más funciones de Managed Agents y de administración para empresas que no caben aquí: conviene leerlas antes de migrar.
