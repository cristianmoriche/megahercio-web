Microsoft convierte Windows en un sistema para agentes de IA con ejecución local y contenedores

Microsoft ha presentado el 17 de noviembre de 2026 en su conferencia Ignite un paquete de novedades para Windows 11, Windows 365 y Windows Server 2028 centrado en ejecutar y aislar agentes de inteligencia artificial entre el ordenador local y la nube.

Edición y revisión: Cristian Moriche · Publicada el 17 de noviembre de 2026 a las 22:20

Texto elaborado con ayuda de inteligencia artificial a partir de las fuentes citadas. Política editorial

Claves

  • Microsoft Execution Containers añade aislamiento por proceso y micro máquinas virtuales experimentales para agentes.
  • GitHub Copilot Fusion ya enruta tareas de programación hacia modelos locales en ordenadores con chips de NVIDIA y AMD.
  • Windows Server 2028 entra en vista previa pública con Microsoft Foundry y soporte futuro para aceleradores AMD MI350P.

Microsoft ha aprovechado la jornada inaugural de su conferencia anual Ignite en San Francisco para reorientar su sistema operativo hacia la ejecución de agentes de inteligencia artificial. La compañía ha detallado nuevas funciones de aislamiento, enrutamiento híbrido de modelos y gestión unificada entre ordenadores personales, máquinas en la nube y servidores locales.

Qué ha pasado

El 17 de noviembre de 2026, Pavan Davuluri, vicepresidente ejecutivo de Windows y Dispositivos, y Satya Nadella, consejero delegado de Microsoft, presentaron en Ignite 2026 la estrategia que la empresa denomina «inteligencia híbrida» en Windows 11. El objetivo declarado es combinar la ejecución en el propio ordenador con el cálculo en la nube según las necesidades de cada tarea, reduciendo el gasto en tókenes y manteniendo el control sobre los datos.

Publicidad

En el plano de seguridad base, Microsoft ha anunciado la disponibilidad general de su plataforma de seguridad para puntos finales (endpoint security platform), que traslada protecciones críticas desde el núcleo del sistema (kernel) al espacio de usuario para evitar que un fallo de un proveedor tumbe todo el equipo. A esto se suma la disponibilidad general de la protección de administrador en Windows —que mantiene las cuentas con privilegios estándar por defecto y solo eleva permisos para tareas puntuales verificadas con Windows Hello— y la vista previa de Windows baseline protection, un indicador único que verifica si un equipo cumple requisitos como el arranque seguro y la integridad de memoria.

Además, la compañía ha abierto la vista previa pública de Windows Server 2028, que hereda estas políticas de endurecimiento, añade criptografía poscuántica y permite gestionar servidores y ordenadores personales desde la misma consola con Intune y Windows Autopatch.

Contenedores para agentes y modelo híbrido en local

El núcleo técnico del anuncio gira en torno a Microsoft Execution Containers (MXC), el entorno de aislamiento para agentes disponible de forma general en Windows 11 desde octubre de 2026. MXC impone en tiempo de ejecución a qué archivos y redes puede acceder cada agente. En Ignite, Microsoft ha añadido mejoras en vista previa para contenedores de proceso, modos de aprendizaje y permisivo ya disponibles para observar el comportamiento de un agente antes de bloquearlo, y micro máquinas virtuales locales en fase experimental con aislamiento por hardware. Según la compañía, OpenAI ya activa MXC por defecto en Codex y Meta lo utiliza en decenas de miles de equipos con Windows.

Publicidad

En paralelo, Microsoft Copilot recibirá próximamente tres funciones locales en los equipos Copilot+ PC: contexto local sobre archivos y aplicaciones abiertas, acciones locales para organizar documentos o diagnosticar fallos de Bluetooth o red en modo solo lectura, y modelos que se ejecutan directamente en el dispositivo. Para desarrolladores, GitHub Copilot Fusion ya permite en vista previa derivar tareas de código a modelos locales como MAI Code 1.1 Flash en equipos con chips NVIDIA RTX Spark y procesadores AMD Ryzen AI Max y Ryzen AI Max 400.

En la nube, Microsoft ha presentado Direct Stream para Windows 365 y Azure Virtual Desktop, una tecnología de transmisión que mejora cerca de un 300 % la fiabilidad de conexión frente al lanzamiento original del servicio y que el año próximo permitirá transmitir hasta dos pantallas 4K a 60 fotogramas por segundo con color 4:4:4 en instancias con GPU de NVIDIA. También ha hecho elegible Windows 365 for Agents para el sistema de créditos Copilot Credits.

Por qué importa

El despliegue de agentes autónomos en empresas choca con dos frenos habituales: el coste variable de enviar cada operación a la nube y el riesgo de dar acceso sin control a carpetas o redes internas. Al integrar el aislamiento en el propio sistema operativo y combinarlo con IA local en el PC, Microsoft intenta convertir la flota de ordenadores y servidores Windows en infraestructura de cómputo propia para reducir la factura de inferencia.

A la vez, trasladar los agentes de seguridad fuera del núcleo del sistema responde a una exigencia directa de estabilidad en ciberseguridad empresarial tras incidentes graves en años anteriores. Unificar la gestión de servidores y portátiles bajo Intune y Autopatch busca simplificar el mantenimiento a los departamentos de sistemas, donde Microsoft asegura que Autopatch acelera el despliegue de parches más de un 40 % frente a la gestión tradicional en local.

Qué falta por saber

Microsoft no ha concretado una fecha cerrada para la llegada de las funciones locales de contexto, acciones y diagnóstico a los equipos Copilot+ PC, ni para el lanzamiento final de Windows Server 2028. Tampoco ha detallado los precios de las futuras máquinas en la nube con GPU para Direct Stream ni la fecha exacta de la vista previa del acelerador AMD MI350P en Windows Server, prevista para la primera mitad de 2027.
